# Corpus candidates — hand this file to a teammate, not a technique.
#
#   node scripts/capture-page.mjs --list bench/corpus-candidates.txt
#
# Captures land in bench/realpages/ and bench/realpages-drill.ts picks them up with no
# further wiring. Re-run ./test-all.sh afterwards: growing this corpus has found a real
# defect every single time it has grown, so expect the drill to go red and treat that as
# the point of the exercise rather than as a problem with the capture.
#
# ⛔ THE TWO RULES, AND THEY ARE NOT NEGOTIABLE
#
# 1. PUBLIC, LOGGED-OUT PAGES ONLY. Never capture while signed in. Everything in
#    realpages/ is a logged-out page, which is the only reason the drill is allowed to
#    print every value it withheld. This is not hypothetical: a capture taken during a
#    signed-in session is how a teammate's personal email address and a real mobile
#    number ended up committed to this repository, and taking them back out on 23 Sep
#    2026 required rewriting the whole history.
# 2. CAPTURE ONLY PAGES YOU MAY CAPTURE. If a site's terms forbid automated access,
#    leave it out and record it below rather than working around the block.
#
# Lines are `name<TAB>url`. Blank lines and #-comments are ignored. A page under 100
# nodes is refused rather than saved — an un-hydrated shell would join the corpus and
# test nothing, which is worse than a failed capture.
#
# ── Already captured (do not re-add) ────────────────────────────────────────────
# cleartax · digilocker · hn · incometax · india_gov · mygov · pgportal
# python_org · rbi · sebi · uidai · wiki_pan · wikipedia
#
# ── Known to block automation — recorded, NOT worked around ──────────────────────
# epfindia, nsdl, passportindia: all three refuse the driver even headed at 12 s.
# Do not retry these; if one ever becomes capturable, add it here with a note.
